# Live Translate

Ứng dụng web dịch hội thoại, cuộc họp trực tiếp hai chiều cho 7 ngôn ngữ: Việt, Anh, Hoa, Nhật, Hàn, Đức, Pháp.

- Địa chỉ dùng: https://lamthevinhscue-hub.github.io/live-translate/
- Nhận diện giọng nói: Azure Speech (tự nhận diện ngôn ngữ) hoặc Web Speech của trình duyệt.
- Dịch: Google Translate, Azure Translator hoặc OpenAI GPT.
- Mã nguồn không chứa khóa API. Mỗi thiết bị tự nhập khóa hoặc nhập tệp cấu hình mã hóa.
